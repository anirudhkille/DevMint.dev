# 🚀 DevMint.dev — Modern Developer Tools (Open Source)

DevMint.dev is a fast, minimal, and beautifully designed collection of free developer tools.  
No ads. No tracking. No bloat. Just tools that work.

Built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

---

## ✨ Features

- ⚡ Lightning-fast UI
- 🎨 Clean, modern, minimal design
- 🌗 Full dark mode support
- 📱 Fully responsive
- 📦 Modular tool architecture
- 🔍 SEO-optimized pages
- 🚀 Deployed on Vercel
- 🔒 Privacy-friendly (no analytics unless self-added)

---

## 🧰 Available Tools

### **🖼 Image Compressor**

Compress PNG, JPG, and WebP images with adjustable quality.

### **🏷 Meta Tag Generator**

Generate SEO-friendly meta tags & Open Graph preview.

### **🧱 JSON Formatter**

Format, minify, and validate JSON instantly.

### **🎨 Gradient Generator**

Create smooth CSS gradients with live preview.

### **🖼 Favicon Generator**

Generate all favicon sizes from a single image.

### **🎨 Color Palette Generator**

Extract and generate color palettes easily.

### **🔳 QR Code Generator**

Generate QR codes for URLs or text. Client-side with no external API.

### **🔠 Text Case Converter**

Convert text between multiple case formats.

### **🔡 Base64 Encoder / Decoder**

Encode text to Base64 or decode Base64 strings instantly.

### **🔐 Bcrypt Generator**

Generate bcrypt password hashes and verify bcrypt hashes in your browser.

### **🤖 Robots.txt Generator**

Build valid robots.txt rules with user-agent groups, allow/disallow paths, crawl delays, and sitemaps.

### **📋 HTTP Status Codes Reference**

Search and filter HTTP status codes by category with clear explanations.

### **🧹 HTML Minifier**

Minify HTML for production or format it back into readable markup.

### **🆔 UUID Generator**

Generate random UUID v4 identifiers in bulk with uppercase and hyphen-free options.

### **🔐 Hash Generator**

Generate MD5, SHA-1, SHA-256, SHA-384, and SHA-512 hashes from any text in your browser.

### **🔑 JWT Decoder**

Decode JSON Web Token headers, payloads, and claims in your browser. Inspect expiration without sending tokens anywhere.

### **🔄 YAML to JSON Converter**

Convert YAML to JSON or JSON to YAML instantly in your browser with clear error messages.

### **🎨 Color Converter**

Convert colors between HEX, RGB, and HSL and check WCAG contrast ratios in your browser.
